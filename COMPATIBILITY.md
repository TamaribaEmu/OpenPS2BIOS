# Game compatibility

[Back to the README](README.md)

All entries below are listed as **Reaches main menu**. This records menu access
only; it does not establish that gameplay, controller input, audio or saving work
correctly. Results are for emulator use, with PCSX2 as the current test target.

Separate discs and patched editions have their own entries. Regions and versions
are included where known. The list contains 38 game and disc entries.

To report a result or correction, open an issue with the game edition, BIOS build,
emulator version, settings and steps to reproduce it. Include how far you tested
and any problems you found. See [Contributing](README.md#contributing) for details.
